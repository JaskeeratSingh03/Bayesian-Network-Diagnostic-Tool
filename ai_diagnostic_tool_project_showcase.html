Core Algorithms

How the Bayesian Engine Works

Mathematical rigor replaces guesswork. Here is the probabilistic architecture powering `src.engine` and `main.py`.

01

Posterior Belief Propagation

Every fault $F$ starts with an empirical prior $P(F)$. As symptoms $E = \{e_1, e_2, ...\}$ are observed, Bayes' Rule computes exact posteriors:

P(Fault | Evidence) = α · P(Fault) · ∏ P(e_i | Parents(e_i))
02

Next-Best-Test via Entropy Reduction

Instead of randomly disassembling a laptop, the engine calculates the Mutual Information (Information Gain) of each diagnostic test:

Best_Test = argmax [ H(Faults) - E_result[ H(Faults | Test = result) ] ]

This guarantees the technician performs the test that yields maximum certainty with the least effort.

03

Robustness to Incomplete Evidence

Real repairs involve missing information. If a technician does not know if the screen flickers or cannot test the RAM yet, the marginalization over unobserved latent variables continues seamlessly without failing.

from src.engine import setup_laptop_network

def main():
    net = setup_laptop_network()
    faults = ["Dead Battery", "Fried Motherboard", "Corrupted RAM"]
    symptoms = ["Won't Boot", "Screen Flickers", "Beeping"]
    tests = ["Voltage Check", "RAM Swap Test"]

    # Continuous inference loop
    while True:
        for f in faults:
            print(f"{f}: {net.get_posterior(f):.2%}")

        # Dynamic Next-Best-Test Selection
        best_test = net.recommend_next_test(tests, faults)
        if best_test:
            print(f"Recommended Test: {best_test}")
